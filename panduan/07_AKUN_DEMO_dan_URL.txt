 TIPS:

    biarkan untuk demo) lewat menu  Profil.
  - Menu  Manajemen Pengguna  (Admin) punya kolom NIM/NIDN.
    Field ini OPSIONAL, tapi WAJIB unik, dan bisa dipakai
    untuk login (mis. ketik  2022101  di kolom username).

    maupun menu Pengguna. Endpoint /api/audit-logs hanya
    untuk Admin.
  - QR Code inventori boleh diakses semua user yang login
    (endpoint /api/components/:id/qrcode tidak perlu admin).

 4. API KEY IOT (ESP32)
------------------------------------------------------------
  Device demo bawaan:
      Device ID : ESP32-LAB-001
      API Key   : ilms_esp32_dev_secret_key_123
  Header yang dipakai saat kirim data:
      X-API-Key: ilms_esp32_dev_secret_key_123

  Simulasi kirim heartbeat (tanpa hardware, CMD/PowerShell):
      curl -X POST http://localhost:5000/api/devices/heartbeat ^
           -H "X-API-Key: ilms_esp32_dev_secret_key_123" ^
           -H "Content-Type: application/json" ^
           -d "{\"timestamp\": 123456}"

  Simulasi kirim data sensor:
      curl -X POST http://localhost:5000/api/sensors/readings/batch ^
           -H "X-API-Key: ilms_esp32_dev_secret_key_123" ^
           -H "Content-Type: application/json" ^
           -d "{\"readings\":[{\"sensorType\":\"temperature\",\"value\":29.4,\"unit\":\"C\"},{\"sensorType\":\"humidity\",\"value\":68.2,\"unit\":\"%\"},{\"sensorType\":\"distance\",\"value\":15.0,\"unit\":\"cm\"}]}"

  Lalu buka menu  Monitoring Sensor  untuk melihat grafiknya.

  PENTING: API key demo ini ada di repo publik-ish. Untuk
  produksi, WAJIB ganti (menu Perangkat IoT > Edit > API Key).

 5. ENDPOINT YANG SERING DEMO-DITUNJUKKAN
------------------------------------------------------------
  GET  /api/health                        -> status server
  POST /api/auth/login                    -> login
  GET  /api/dashboard/summary             -> ringkasan dashboard
  GET  /api/components                    -> daftar inventori
  GET  /api/components/:id/qrcode         -> unduh QR (PNG)
  POST /api/loans                         -> buat peminjaman
  PUT  /api/loans/:id/approve             -> setujui (ADMIN)
  PUT  /api/loans/:id/reject              -> tolak (ADMIN)
  PUT  /api/loans/:id/return              -> proses pengembalian (ADMIN)
  PUT  /api/loans/:id/cancel              -> batalkan
  GET  /api/sensors/readings              -> data sensor
  GET  /api/reports/inventory             -> laporan JSON
  GET  /api/reports/inventory?format=csv  -> unduh CSV
  GET  /api/audit-logs                    -> log audit (ADMIN ONLY)
  GET  /api/audit-logs/facets             -> pilihan filter audit
  GET  /api/tickets                       -> tiket CS
  GET  /api/tickets/stats                 -> statistik tiket
  POST /api/tickets                       -> buat tiket
  POST /api/tickets/:id/replies           -> balas tiket
  PUT  /api/tickets/:id                   -> ubah status (admin)
  PUT  /api/tickets/:id/close             -> tutup tiket

  Daftar lengkap + contoh request/response:  docs\API.md
