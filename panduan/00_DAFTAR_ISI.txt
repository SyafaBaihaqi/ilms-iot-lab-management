------------------------------------------------------------
 ATURAN EMAS (baca dulu)
------------------------------------------------------------
 1. Selalu jalankan dari CMD, bukan PowerShell.
    (PowerShell sering menolak "npm" - lihat file 05)
 2. Untuk PowerShell, pakai "npm.cmd" (bukan "npm").
 3. Jangan pernah commit file .env atau iot\esp32\config.h
    (sudah otomatis di-ignore oleh .gitignore).
 4. Sebelum demo/presentasi, ALWAYS jalankan file 02 supaya
    online & siap dipamerkan.
