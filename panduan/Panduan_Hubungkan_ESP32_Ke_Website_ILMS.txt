# LANGKAH-LANGKAH SETUP MENGHUBUNGKAN ESP32 KE WEBSITE ILMS

## Prasyarat
- ESP32 Dev Board
- Sensor DHT22 (opsional, sudah diprogram)
- Kabel USB, Arduino IDE / VS Code + PlatformIO
- Backend ILMS sudah berjalan (http://localhost:5000 atau URL online)
- ESP32 dan komputer/hosting berada dalam jaringan yang sama (untuk testing LAN)

---

## LANGKAH 1: Buka Folder Firmware ESP32
Masuk ke direktori project:
```bash
cd D:\Study\Prototype\ILMS\iot\esp32
```

File yang dibutuhkan:
- `config.example.h` → template konfigurasi
- `sensor_node.ino` → firmware ESP32
- `platformio.ini` → konfigurasi PlatformIO (opsional)

---

## LANGKAH 2: Buat File Konfigurasi config.h
Salin `config.example.h` menjadi `config.h`.

**Di Windows (PowerShell):**
```powershell
Copy-Item "config.example.h" "config.h"
```

**Di Arduino IDE:** Rename `config.example.h` → `config.h`

Buka `config.h` dan ubah nilai berikut:

```cpp
#ifndef ILMS_CONFIG_H
#define ILMS_CONFIG_H

// WiFi
#define WIFI_SSID       "NAMA_WIFI_KAMU"
#define WIFI_PASSWORD   "PASSWORD_WIFI_KAMU"

// URL Backend API
// JANGAN pakai http://localhost:5000 untuk ESP32
// Gunakan IP LAN komputer yang menjalankan backend
#define API_BASE_URL    "http://192.168.1.XXX:5000/api"

// Identitas Device
#define DEVICE_NAME     "ESP32 Room Environmental Node"
#define DEVICE_TYPE     "ESP32-SensorNode"
#define ESP32_ID        "ESP32-LAB-NODE-01"

// API Key (diisi setelah registrasi)
#define API_KEY         "ILMS_DEV_API_KEY_HERE"

// Pin Sensor
#define PIN_DHT         4
#define PIN_ULTRASONIC_TRIG 12
#define PIN_ULTRASONIC_ECHO 14

// Interval
#define HEARTBEAT_INTERVAL_MS    60000UL
#define SENSOR_INTERVAL_MS       30000UL

#endif
```

> **PENTING:** Gunakan IP LAN (ipconfig) bukan `localhost`.

---

## LANGKAH 3: Registrasi Device ESP32 ke Website ILMS
Dapatkan API Key via cURL/Postman/Thunder Client.

### cURL
```bash
curl -X POST http://localhost:5000/api/devices/register \
  -H "Content-Type: application/json" \
  -d '{"esp32Id":"ESP32-LAB-NODE-01","deviceName":"ESP32 Room Environmental Node","deviceType":"ESP32-SensorNode","firmwareVersion":"1.0.0","location":"Laboratorium IoT"}'
```

### Response
```json
{
  "success": true,
  "data": {
    "esp32Id": "ESP32-LAB-NODE-01",
    "apiKey": "ilms_dev_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  }
}
```

> `apiKey` hanya muncul sekali saat registrasi pertama.

---

## LANGKAH 4: Masukkan API Key ke config.h
Salin `apiKey` ke `config.h`:

```cpp
#define API_KEY         "ilms_dev_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

## LANGKAH 5: Install Library
Arduino IDE Library Manager:
- ArduinoJson (v7.x)
- DHT sensor library (Adafruit)
- Adafruit Unified Sensor (Adafruit)

PlatformIO: sudah ada di `platformio.ini`.

---

## LANGKAH 6: Upload Firmware
**Arduino IDE:** Buka `sensor_node.ino` → Pilih `ESP32 Dev Module` & Port → Upload

**PlatformIO:**
```bash
cd iot/esp32
pio run --target upload
pio device monitor
```

---

## LANGKAH 7: Cek Koneksi
Lihat Serial Monitor:
```text
[WIFI] Connected. IP: 192.168.100.50
[HTTP] /devices/heartbeat 200
[HTTP] /sensors/readings/batch 200
```

---

## LANGKAH 8: Verifikasi di Website
Login Admin/Dosen → **Monitoring Sensor** atau **Perangkat IoT**. Device akan muncul dengan status **Online**. Cek **Laporan → IoT Device** untuk melihat data sensor bertambah tiap 30 detik.

---

## TROUBLESHOOTING
| Masalah | Solusi |
|---|---|
| Tidak bisa konek WiFi | Periksa SSID/Password di config.h |
| HTTP 401 | Cek API_KEY, bisa hapus NVS & register ulang |
| Tidak bisa akses backend | Gunakan IP LAN, bukan localhost |
| Device Offline | Cek jaringan, port 5000 terbuka |
| esp32Id duplikat | Gunakan ID unik atau hapus device lama |

---

## CATATAN
- Request ESP32 tidak kena CORS
- Untuk online pakai domain HTTPS
- Job offline akan tandai device Offline jika > 2 menit tanpa heartbeat
- API key disimpan terenkripsi (bcrypt) di DB
