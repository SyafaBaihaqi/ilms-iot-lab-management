 2. TEKNOLOGI YANG DIPAKAI
------------------------------------------------------------
 BACKEND
   Node.js + Express ......... REST API
   Prisma ORM ................ akses database (aman dari SQL injection)
   JWT + refresh token ....... autentikasi
   bcrypt .................... hash password
   zod ...................... validasi input
   qrcode ................... generate QR Code (PNG/SVG)
   helmet + cors + rate-limit keamanan (header, CORS, throttle)
   bcryptjs ................. hash password
   vitest + supertest ........ test otomatis

 FRONTEND
   React 18 + TypeScript ..... UI
   Vite ..................... build tool (cepat)
   Tailwind CSS ............. styling
   axios .................... HTTP client
   vite-plugin-pwa .......... PWA (bisa install di HP, offline cache)

 DATABASE
   PostgreSQL 16 ............ database relasional
   (via Docker secara lokal, Neon secara online)

 IOT
   ESP32 + Arduino ........... deviceIoT
   REST API + API Key ........ komunikasi device -> server

 INFRA
   Docker ................... container untuk PostgreSQL
   Cloudflare Tunnel ........ publish ke internet tanpa buka port
   Render + Vercel + Neon .... hosting permanen gratis
   GitHub Actions ............ keep-alive Render
