IoT Lab Management System (ILMS)

PRESENTASI SINGKAT (1-2 Menit)

1. LATAR BELAKANG (15 detik)
ILMS adalah sistem manajemen laboratorium IoT berbasis web untuk mengelola inventaris komponen, alur peminjaman-pengembalian, perangkat IoT, monitoring data sensor, serta portofolio proyek laboratorium. Tujuannya menggantikan pencatatan manual menjadi sistem terpusat, terstruktur, dan dapat diaudit.

2. PROBLEMATIKA YANG DISELESAIKAN (15 detik)
Pencatatan stok komponen masih manual, sulit melacak siapa yang meminjam, risiko stok kurang tidak terdeteksi, peminjaman terlambat tidak terpantau, dokumentasi proyek mahasiswa berserakan, serta sulit menghasilkan laporan untuk administrasi dan audit. ILMS menjawab semua itu dengan mekanisme terotomatisasi.

3. FITUR UTAMA (50 detik)
- Manajemen inventaris dan stok real-time dengan riwayat perubahan stok.
- Alur peminjaman terstruktur: pengajuan -> persetujuan (Admin/Dosen) -> peminjaman -> pengembalian, dengan validasi stok dalam transaksi database.
- RBAC terperinci: Admin (penuh), Dosen (operasional lab, tanpa pengelolaan pengguna dan log audit), Mahasiswa dan User (peminjam).
- Manajemen Pengguna dengan filter berdasarkan role dan status (aktif/nonaktif) serta pencarian nama/username/NIM/email.
- Laporan lengkap: Inventaris, Peminjaman, Kerusakan, IoT. Ekspor ke CSV, Excel (.xlsx), dan PDF (multi-halaman). Tersedia juga Surat Peminjaman per transaksi (PDF).
- Dashboard adaptif per peran: Admin/Dosen, Mahasiswa, dan User sederhana.
- Portofolio Proyek Elektronik/IoT: penandaan Featured, Proyek Terpilih (Star/Trending), section Proyek Mahasiswa, identitas author, dan halaman Showcase yang menampilkan project.saiasyap.my.id. Penambahan proyek khusus Admin, peran lain hanya melihat.
- Customer Service (ticketing) dengan thread balasan dan notifikasi ke staff.
- QR Code label komponen dan pemindaian cepat di halaman Inventori.
- IoT (ESP32): registrasi perangkat, heartbeat, dan pengiriman data sensor via API key khusus.
- PWA, log audit, notifikasi in-app, deteksi device offline, dan penandaan peminjaman terlambat.

4. TEKNOLOGI & ARSITEKTUR (20 detik)
Frontend: React + Vite + TypeScript + Tailwind, PWA (Workbox).
Backend: Node.js + Express + TypeScript + Zod + JWT + Prisma ORM.
Database: PostgreSQL.
IoT: ESP32 (ArduinoJson). Arsitektur memisahkan API web (JWT) dan endpoint IoT (API key) untuk keamanan.

5. KUALITAS & IMPLEMENTASI (15 detik)
Terdapat 97 test otomatis (Vitest + Supertest) pada database terpisah (ilms_test), type-safe dengan TypeScript, validasi input, dan RBAC ketat. Dilengkapi E2E smoke test untuk QR dan hak akses per peran. Siap dideploy ke ilms.saiasyap.my.id.

6. PENUTUP (10 detik)
ILMS adalah solusi terintegrasi untuk manajemen laboratorium IoT: terstruktur, terdokumentasi, mudah di-deploy, dan siap dikembangkan lebih lanjut.
